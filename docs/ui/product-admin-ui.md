# 商品管理后台 UI 规范

## 设计原则

界面使用 Ant Design 构建克制、清晰的管理后台。信息密度以完成商品运营任务为准，不增加规格之外的看板、统计或状态流转。正文和交互文字满足 WCAG AA 对比度；键盘焦点始终可见；状态不能只用颜色表达。

## 页面层级与布局

### 登录页

- 页面使用居中的单列登录区域，桌面最大宽度 400px，窄屏占满可用宽度并保留 24px 页面边距。
- 层级依次为产品名“StockStack”、页面标题“管理员登录”、账号和密码字段、通用错误提示、登录按钮。
- 不展示测试账号、密码规则或任何已提交凭据。

### 认证后后台壳

- 顶部栏展示产品名和当前区域；主内容区承载商品管理或发布/编辑页。
- 本期默认进入“商品管理”。任务 8 只实现可识别的轻量占位内容，不提前实现列表、发布或编辑逻辑。
- 页面标题使用一级标题；区块标题使用二级标题，保持唯一、连续的语义层级。

### 商品管理页

- 桌面从上至下为页面标题与主操作、组合筛选、批量操作、商品表格、分页。
- 表格仅呈现规格定义的商品字段和操作。处罚为单商品操作并二次确认；处罚商品不显示恢复、上架或下架操作。
- 筛选和页码保存在 URL 查询参数中。批量操作仅提供上架和下架。

### 发布/编辑页

- 从上至下为页面标题、基础信息、图片、配送与退货、类型专属字段、表单操作。
- 创建时先选择商品类型，再读取活动模板并渲染动态字段；编辑时商品类型只读，并使用商品绑定的模板版本。
- 服务端字段错误定位到对应 `Form.Item`；无法归属具体字段的错误显示在表单顶部。

## Ant Design 组件映射

| 场景 | 组件 | 约束 |
| --- | --- | --- |
| 应用主题 | `ConfigProvider` | 使用统一品牌色、圆角、控件高度和焦点样式 |
| 页面结构 | `Layout`、`Space`、`Flex`、`Typography` | 不使用纯视觉 DOM 代替标题语义 |
| 登录与商品编辑 | `Form`、`Input`、`Input.Password`、`InputNumber`、`Select`、`DatePicker`、`Upload` | 每个控件有可关联的可见标签；错误由 `help` 与 `validateStatus` 呈现 |
| 主次操作 | `Button` | 每页仅一个默认主操作；危险操作使用 `danger` 并确认 |
| 通用与字段错误 | `Alert`、`Form.Item` | `Alert` 使用 `role="alert"`；字段错误与控件关联 |
| 筛选与列表 | `Form`、`Table`、`Pagination` | 表头语义完整；加载时保留页面结构 |
| 状态 | `Tag` | 必须包含中文状态文本与图标/符号，不仅改变颜色 |
| 危险确认 | `Modal` | 初始焦点置于取消按钮；说明影响对象与不可逆性 |
| 窄屏补充信息 | `Descriptions` 或纵向卡片 | 保持字段名称，不以位置或颜色代替标签 |

## 视觉与状态语义

- 品牌主色：`#1677ff`，用于主操作、选中和可交互强调。
- 页面背景：`#f5f7fa`；内容背景：`#ffffff`；主文字：`#1f2329`；次文字：`#5f6b7a`；边框：`#d9dfe8`。
- 圆角：控件 6px、内容容器 8px；基础间距按 8px 倍数使用，表单字段间距 16px，区块间距 24px。
- 上架：绿色 Tag，文本“上架”，配对勾图标。
- 下架：中性灰 Tag，文本“下架”，配暂停图标。
- 处罚：红色 Tag，文本“处罚”，配禁用图标；所有列表和详情保持相同表达，且不提供恢复操作。
- 成功、警告、失败反馈均含明确文字或图标。对比度不足的浅色只作为背景，不承载唯一语义。

## 焦点顺序与键盘操作

### 登录

焦点顺序为管理员账号、密码、登录按钮。`Enter` 在账号或密码字段提交表单；提交期间按钮进入 loading 且禁止重复提交。失败后焦点移至错误摘要；字段校验失败时聚焦首个错误字段。

### 商品管理

焦点顺序为跳转主内容、页面主操作、筛选字段、查询/重置、批量选择与批量操作、表格行内操作、分页。`Tab` 和 `Shift+Tab` 顺序移动；`Enter` 或 `Space` 激活按钮、复选框和菜单；`Escape` 关闭菜单或确认框并恢复触发点焦点。

### 发布/编辑

焦点按视觉上的自上而下、从左到右顺序经过字段，动态字段插入在类型选择之后的既定区块。图片删除和排序操作有可读名称。提交失败后聚焦错误摘要，摘要链接允许跳到对应字段。

所有交互控件的可点击区域至少 44px，高对比焦点环不被容器裁剪；禁用状态同时通过属性和视觉表现传达。

## 窄屏策略

- 断点以 768px 为主要切换点；内容不依赖固定桌面宽度，支持 320px 视口与浏览器文字放大至 200%。
- 登录区域取消卡片阴影并使用全宽按钮。
- 顶部栏保留产品名和当前页标题；次要导航收纳为可键盘操作的抽屉。
- 商品筛选改为单列，查询与重置按钮全宽或并排等宽；主操作置于标题下方。
- 商品列表改为纵向卡片/描述列表，仅首屏展示商品标识、标题、类型、价格、库存和带文字的状态；其余字段和操作通过“更多”展开。批量选择仍使用明确复选框，不以滑动手势作为唯一入口。
- 发布/编辑表单由多列转为单列；底部操作保持正常文档流，避免软键盘遮挡固定按钮。
- 内容允许纵向滚动，不产生页面级横向滚动；超长标题可换行，商品 ID 可复制且允许断行。

## 加载、空状态与错误

- 登录按钮使用自身 loading 状态；页面级数据加载使用 `Skeleton`，不以空白页代替。
- 空列表说明当前筛选无结果，并提供清除筛选入口；无权限或会话失效直接回到登录页。
- 401 清除当前 `sessionStorage` token 后回到登录，不显示或记录凭据。
- 网络或通用服务端错误使用简洁、可恢复的文案；字段错误必须保留服务端给出的字段路径并定位到对应控件。
